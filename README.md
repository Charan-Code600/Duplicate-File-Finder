



# 🔍 Duplicate File Finder

A Python tool that scans a folder and finds duplicate files.

## Features
- 🔍 Scans folder for duplicate files
- ⚠️ Shows list of duplicates found
- 🗑️ Option to delete duplicates
- ❌ Error handling for invalid paths

## How to Run
```bash
python duplicate_finder.py
```

## How to Use
1. Run the program
2. Enter folder path
3. See duplicate files
4. Choose to delete or keep them

- Python
- os module
